## 📌 Featured projects

| Project | What it does | Result |
|---|---|---|
| [**Ovarian carcinoma diagnosis from ultrasound**](https://github.com/Amit-Brilant/ovarian-cancer-tvus-pipeline) | M.Sc. thesis. EfficientNet-B7 triage, YOLOv8 lesion localisation, and a benign vs malignant classifier fusing CNN embeddings with Segment Anything shape features. Public code and dataset | 0.952 accuracy, 0.964 AUC (patient level) |
| [**Self-supervised cell segmentation**](https://github.com/Amit-Brilant/cell-segmentation-byol-unet) | BYOL pretraining of a U-Net encoder on unlabelled microscopy, then fine-tuning for 3-class segmentation | Up to +12.4% mean SEG over the supervised baseline |
| [**Virtual biopsy for early melanoma detection**](https://github.com/Amit-Brilant/rcm-nevi-composite-pattern-classification) | B.Sc. final project with Sheba Medical Center. ConvNeXt on confocal microscopy tiles, with a clinical penalty matrix in both the loss and the metric | 90.7% clinically weighted accuracy |
